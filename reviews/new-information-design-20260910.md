# 从冗余参考转向新证据：设计边界与离线可行性（2026-09-10）

状态：用户同意重新设计“额外信息究竟增加了什么”。本轮仅设计、重建同九world的无目标规则集合和分区计算，未调用模型、未抽取新目标、未释放任何新增目标标签、未运行oracle/K4。3项合成测试通过。新实验尚未冻结，不沿用旧54＋2预算。

## 1. 首先区分三个问题

| 额外材料 | 增加的是什么 | 能回答什么 |
|---|---|---|
| 已有候选的数值表／解释 | 冗余表示、计算帮助或注意提示 | 表示是否帮助入口选择；上一轮已测，结果混合 |
| 原观察不能确定的真实实验结果 | 关于未知规则的新证据 | 模型是否利用新证据修正假设或改善未见点预测 |
| 与目标无直接对应的类比、噪声、外部素材 | 可能增加可想到的候选或搜索路径 | 非答案性启发能否打开探索方向；不能等同于直接补充目标观察 |

原研究愿景包括第三种，第二种可作为较清楚的新信息利用检查，但**不是第三种已经实现的替代品**。不给正确option不代表没有目标相关线索；真实观测虽不直接给完整规则，也属于有意提供的目标信息，必须如实说明。

上一轮附加表不新增独立目标观测，其数值来自候选已有子表达式。但提示“哪部分值得关注”仍可能有作用，且cohort曾按目标结果筛选，因此没有据此证明条件互信息严格为零。“冗余可能解释空结果”仍是合理解释，不是已识别的唯一原因。

## 2. 非答案性如何给出可检查的定义

利用已有每world的256条规则集合：它们都与初始12条D0观察一致，彼此全域行为不同。在一个新的输入点q上，对所有规则分别计算预测0和1的数量。

- 若两组均非空，新真实标签会排除一部分原本可行的规则；不是仅换一种方式表达已知观察。
- 本轮进一步要求两组都至少保留2条规则，防止新增一条观察直接唯一确定规则。
- 选择时不读取实际目标或其新标签：在原49个evidence点内，先选分组最均衡的点，再用固定公开prompt哈希打破并列。没有按新模型表现或实际标签筛选。
- 分组大小是有限规则集合的代码性质，不是模型内部熵、信念或实际成功概率。均匀规则集合下的期望信息量仅是参考计算，不声称这是条件化cohort的真实先验。

注意：两组均有多条规则只排除“这一观察单独唯一确定完整规则”，并不排除它恰好使某个特定动作显而易见。因此不能把该条件称为排除了所有答案线索或shortcut。

## 4. 现有数据约束：不能直接接旧K4评分

独立只读代码检查确认：Spark域125点已全部分为D0 12、ordered evidence 49、private test 64，没有空闲reserve。其他通用world模块的probe／未分配点不能冒充本实验的保留资源。

- 新标签若来自原evidence，属于提前释放原验证可提供的目标信息。必须在独立新协议中指定其作为观察、从后续验证预算中移除或明确记账；改变的是信息协议，不能重写旧world／hash冒充旧实验。
- 不使用private test标签生成提示，保留原64点用于最后评分。必须先固定新评分与数据用途，不能边看测试结果边挑观察。
- 旧compressor要求V0全部符合D0，并按固定evidence顺序工作；增加新观察后，V0和oracle序列/预算含义可能改变。直接沿用旧K4正确option无法回答模型是否使用了新证据。
- 原九world已用于开发与模型测试，不能改称新held-out world；再使用只作为探索性配对检查。

## 5. 可讨论的新小实验，而非本轮自动授权项

更直接的方案是从“入口动作选择”向“根据新证据提出／修正一个候选规律”迈一小步：

1. 三条件都提供同样的D0、parent和完整的合法程序语法说明，不显示完整十个已构造探索候选作为答案菜单。
2. baseline不加观察；new-evidence增加上述q的真实目标标签；repeat-evidence重复一条已知D0观察，控制“多一行数据”的影响。三组不提示哪条规则正确。
3. 模型输出一条候选程序，由代码验证其格式、已知观察一致性，并在未进入提示的64测试点评分。模型开始承担候选规律生成，而不只是挑选编辑入口。
4. 主描述可用逐world未见点准确率；完整规律恢复只能是更严格的附加结果。一条新二元观察后仍有61–195条可行规则，不能要求模型必然唯一恢复目标。64点也不是64个独立world。
5. 若保留这九world，每world三条件为27次正式请求的设计规模，不再人为沿用原双context来算54个独立问题。模型、预算和技术失败规则尚待单独明确。

重复D0是一个诚实的冗余对照，但输入位置与“是否见过”的表面特征不匹配。没有找到未见而冗余的evidence点，不能捏造假观察、取test点或隐式扩world补齐，也不声称严格等信息量。新标签需按原冻结target绑定获得，不重新抽目标；本轮尚未执行此步骤。

这改变了模型职责和主评分，不是给旧实验换提示那么小的变动。**需要用户确认是否接受“新增真实证据利用／候选规律修正”的独立补充方向后，再实现新评分、标签释放与公共材料。** 若用户仍希望专测看似无关的启发，不应以此替代；要另定义候选空间扩展／新思路产生的操作化，不能把新增目标观测称为无关噪声。
