# 原始假设偏差与研究价值评估（2026-09-11）

记录性质：按用户要求保存本次整体讨论总结。以下区分实验事实、解释边界和助手的价值判断；建议不等于用户已经决定论文方向或批准下一任务。本轮只保存文档，不新增实验、不修改冻结结果或论文正文。

## 总体判断

与最初想得到的正向证据相比，偏差已经比较大；研究仍有价值，但已经从“为一种发现机制提供初步支持”，转成了“拆解探索过程，并展示其中的能力边界”。这不是同一份价值，不能用“负结果也有价值”一句话把损失抹平。

## 1. 距离最初假设，究竟差在哪里？

用户最初的核心目标不是证明AGI，而是做一个小实验，看看：

> 额外信息能否打破当前思路，让模型探索、验证，最后形成更正确的新规律。

现在这条链上的证据并不均衡：

| 原始期待 | 目前证据 | 与期待的距离 |
|---|---|---|
| 看似无关、非答案性的额外信息启发探索 | 主要测了构造context和直接查询到的真实标签 | 较大：原始“灵感／噪声”问题没有被直接验证 |
| 模型根据context改变探索入口 | 在部分配置、经过筛选的任务中观察到了 | 局部支持，但任务和替代解释限制明显 |
| 模型找到反例，并根据反馈修订猜想 | 新版两轮实验中观察到了 | 有行为证据，但仍可能只是普通的证据拟合 |
| 修订后得到更好的规律或预测 | 主动组平均下降，且不如随机组 | 核心预期未获得支持，本设置下方向相反 |
| 过程体现内部增熵—降熵机制 | 没有相应的内部测量与因果识别 | 尚未检验，不是已被否定 |
| 这种能力与RSI的必要条件有关 | 仍是研究动机和理论判断 | 实验没有建立这层联系 |

依据见[原始动机记录](../TODO-20260908.md)和[新版结果报告](microloop-revised-model-results-20260911.md)。

最关键的偏差不是“没证明RSI”——用户本来就没有要求做到。真正没有兑现的是那个更小的期待：能否通过这套探索过程，得到一条可信的“模型因此形成了更好知识”的证据。

## 2. 最新结果削弱了什么，又没有削弱什么？

新版实验已经解决语法问题，没有缺失，所有回答都符合当时的可见证据。但：

- 主动选点：71.35% → 65.10%。
- 随机选点：71.35% → 73.05%。
- 主动相对随机：低7.94个百分点，2胜8负2平。

因此，不能再把最新结果描述成“已经正向，只是样本少、不显著”。这轮主动策略的观测结果就是负向的。小样本限制的是推广强度，不会把负向差异变成正向支持。数值来源为[新版结果报告](microloop-revised-model-results-20260911.md)。

但它也没有推翻全部设想：

- 它只测试了一个有限环境、一个模型配置、两轮反馈。
- 原始的“如何产生有用的外部启发”没有真正被覆盖。
- 两个标签不足以一般性保证从256个候选中唯一恢复目标。
- “可能存在有效的探索流程”与“当前这个流程有效”是两个不同命题。

准确的结论是：当前实现没有验证核心期待；不是已经证明这条思想路线走不通。不过，“尚不能证伪”本身也不能算支持。

## 3. 研究价值打了多少折扣？

不建议给一个看似精确的百分比，因为没有客观的换算标准。以下是按价值类型区分的定性判断，不是投稿概率或学术影响力的量化预测。

### 作为原始idea的正向实证：大幅折扣

原本希望拿到一个小而清楚的正向案例链：

> 额外信息 → 改变探索 → 获得更好的规律。

现在有了前面的局部行为，却没有稳健地接上最后一步。早期正向入口结果还受到样本筛选、简单策略以及后续由代码完成识别等限制。

这意味着目前不能把它当成原始假设已经得到初步实证验证的论文。这是最大的损失，不是措辞稍微保守一点就能补上。

### 作为小规模探索性论文：仍有价值，但吸引力收窄

目前较值得讲的不是“LLM会使用context”或“LLM能拟合观察”，而是：

> 找到反驳当前猜想的信息、生成符合新证据的候选、提高未见预测，是可以分离的能力；当前模型在这个小实验里没有自然地把它们串起来。

主动组更常查询到反驳当前候选的标签：16/24次，随机组为6/24次；但最终预测更差。这是一个有内容的观察，而不只是“模型做题失败”。不过，该反驳数依赖各组不同的当前候选，尚不能证明主动查询具有更高的严格信息增益。详见[过程诊断及限制](microloop-revised-model-results-20260911.md)。

它能支撑一篇有边界的探索报告，但还不能支撑“发现了科学探索的一般瓶颈”这种强结论。

### 作为“快速、短小、资源可控”的项目：效率也打了明显折扣

实验不断扩展、协议修订以及助手造成的提示—解析器缺陷，消耗了原本希望节省的时间和调用资源。

不是所有工程工作都会转化成论文贡献：

- 保存和核验提高可信度，但不是科学创新本身。
- 多跑几轮不自动增加证据强度。
- 修复测试bug恢复的是实验可解释性，不能算新增能力发现。

做了很多工作，与获得了很强的结论，确实不是一回事。测试缺陷属于助手的设计和验证责任，不能让用户把这部分成本理解成假设本身的问题。

## 4. 原始idea本身，需要怎样调整？

目前结果提示，它至少还缺一个重要环节：

> 探索带来反例，不保证选中的新解释更正确。

模型可以淘汰一个猜想，然后从很多仍然符合证据的规则里，选到一个预测更差的替代品。规则更简短、解释更确定，也不保证更接近真实规律。

因此，原始设想需要从“通过扩展和收敛形成发现”，进一步明确为：

> 扩展候选 → 获取有区分力的证据 → 合理选择和保留候选 → 在未见情况中验证改进。

其中，“如何在多个相容候选之间选择、如何避免丢掉已有的有效预测”，现在看来不能被当作自动成立的步骤。

这是对idea有帮助的修正，但属于被实验启发出的下一问题，不是已经验证的新机制。

## 5. 当前论文定位与后续投入建议

助手建议定位为：

> 一个带有明确正向局部观察、负向后续结果和方法局限的小规模探索研究。

而不是：

> 一个已经初步展示类人增熵—降熵科学发现能力的概念验证。

两者之间的距离不小。前者仍值得整理和公开，尤其符合用户“提出问题、引发讨论”的一部分初衷；但如果用户最看重的是“给这个idea找到正向实验证据”，那目前的回报确实明显低于预期。

建议是：值得把现有工作收束成文，不值得仅为了挽回原始结论继续追加实验。是否投稿、投向哪里，还要看最终相关工作定位和文章质量，不能单凭已有工作量判断。此处为建议，不构成用户批准进一步写作、投稿或实验。

## 一句话总结

这项研究目前最有价值的产出，不是证明了期待的发现过程，而是显示：模型能进入探索、能遇到反例、能修订解释，但这条链并不会自动通向更好的知识。这个结论比原始愿景弱很多，却比单纯“实验没成功”更有内容；其适用范围仍限于当前已检验的设置。
